# Saandru -- Python dependencies
#
# Tested with Python 3.11 on Windows. Versions below are pinned to what this
# repo was built and verified against (`pip freeze` on the dev machine) --
# newer patch versions of the same package usually work too, but if something
# breaks, installing these exact versions is the safest fallback.
#
# Only packages actually imported by app.py / src/*.py are listed here. Two
# more things this project needs are NOT pip packages and must be installed
# separately:
#   1. Ollama (https://ollama.com) -- the local AI engine. After installing it,
#      pull the two models this tool uses:
#         ollama pull nomic-embed-text
#         ollama pull qwen2.5:3b-instruct
#         ollama pull qwen2.5:1.5b
#      (Saandru picks between the two qwen2.5 models automatically based on
#      this PC's RAM -- see src/ollama_client.py. Pulling both is safest.)
#   2. Tesseract OCR (https://github.com/UB-Mannheim/tesseract/wiki) -- OPTIONAL,
#      only needed to read scanned/photographed documents (images, scanned PDFs).
#      Plain text/Word/Excel/PowerPoint/PDF documents work without it.
#
# Hardware auto-tiering (see src/ollama_client.py) detects total RAM without a hard
# dependency: Windows via ctypes, Linux via /proc/meminfo. On other platforms (e.g.
# macOS) it will use `psutil` IF installed (`pip install psutil`) -- OPTIONAL, not
# required to run Saandru; without it those platforms just default to the 3b model.
